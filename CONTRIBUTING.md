# Contribution to ModernTerrainGenerator

Thank you for your interest in contributing to **ModernTerrainGenerator**. Please read these guidelines before submitting a contribution.

## Signing the Contributor License Agreement

Before your contribution can be accepted, you must sign the [Contributor License Agreement (CLA)](https://cla-assistant.io/load-studio/ModernTerrainGenerator).

By signing the CLA, you confirm that you have the right to submit your contributions and grant the project the permissions described in that agreement.

## Pull Requests

When submitting a pull request, please follow these requirements:

- You must own the code you submit, or have permission to submit it under a license that allows its use in ModernTerrainGenerator.
- Code from other open-source projects may be included only when its license permits the intended use and redistribution.
- If your contribution contains code or assets covered by a pre-existing license, identify that license and the relevant source in your pull request.
- Prefer original work that you have created and have the right to contribute.
- All contributions are subject to the project's Contributor License Agreement.
- Make a reasonable effort to verify that your changes work as intended.
  - For example, if your code adds an NMS call, test it against the Minecraft version targeted by the branch.
- Where appropriate, contributions should address an existing issue or feature request. If there is no relevant issue, open one first so the proposed change can be discussed.
- The ModernTerrainGenerator maintainers reserve the right to decline any pull request. They will make reasonable efforts to explain decisions and help contributors align their changes with the project.

## Code Style and Formatting

Follow the conventions and formatting used by the existing codebase. Keep changes consistent with nearby code and avoid unrelated formatting changes.

Additional project-specific conventions may be documented here as the project evolves.

This license allows the project to maintain, improve, and distribute your contribution, including as part of releases that may be distributed under the project's applicable license.

You remain free to use, modify, and distribute your own contribution elsewhere, subject to any third-party rights or licenses that apply to the material.

For contributions containing third-party code or assets, you must have the necessary rights and must clearly identify the applicable license and source. Do not submit material that you do not have permission to contribute.

## By Contributing, You Confirm That

- You have read and agree to these contribution guidelines and the project's CLA.
- You have the legal right to submit the code or assets in your contribution.
- Your contribution is your original work, or it is material that you are authorized to submit under a license compatible with the project's intended use.
- You have identified any applicable third-party licenses and sources in your pull request.
- You grant the project the rights described in the CLA.
